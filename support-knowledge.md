## About ColorArchive

ColorArchive is a curated color reference library with 3,066 algorithmically generated colors across 36 hue families, 14 lightness bands, and 6 chroma levels. The website (colorarchive.me) offers:

- Free browsing of all 3,066 colors with hex, HSL, RGB values
- 68+ curated palette collections (editorial themes like "Quiet Luxury", "Nocturne Tech", etc.)
- 204 color guides for various industries and use cases
- AI-powered tools: Brand Color Generator, Mood Palette, Design Critique, URL Analyzer
- Cloud Projects (save and organize palettes)
- Figma Plugin with Cloud Sync
- Word-to-Color generator
- PNG export, Design Preview (5 scenes + Dark Mode)
- Free palette pack download
- Pro subscription for advanced features

## Common Questions & Answers

### "What formats are included?"
All packs include CSS variables, Tailwind CSS 4 tokens, and JSON data at minimum. Higher-tier packs include additional formats like SCSS maps, Figma tokens, Style Dictionary, SwiftUI, Android XML, Flutter Dart, and CSS-in-JS exports.

### "Can I use these in my commercial project?"
Yes. All purchased packs include a commercial license for use in client and personal projects.

### "Which pack should I buy?"
- Just exploring? Start with Palette Pack Vol. 1 (¥599)
- Need a brand system? Brand Color Starter Kit (¥1,499)
- Building a SaaS with dark mode? Dark Mode UI Kit (¥999)
- Want everything? All Access Bundle (¥3,999) saves ~40%

### "Do you offer bulk/team pricing?"
Contact support@colorarchive.me for team licensing inquiries.

### "I didn't receive my download"
Check your spam/junk folder. The download link is sent to the email used at checkout. If still missing, reply with your order details and we'll resend.

### "Can I get an invoice?"
Stripe automatically generates receipts. If you need a formal invoice, provide your billing details and we'll arrange it.

### "Is there an API?"
Yes, Pro subscribers get API access for programmatic color lookups and palette generation.
