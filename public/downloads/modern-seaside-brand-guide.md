# Brand Usage Guide: Modern Seaside

This collection balances air, water, and contrast. It works for dashboards, travel, lifestyle products, and any surface that needs calm energy.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Seafoam Whisper Soft** · #EAF5EE

### Slot 2: Secondary (UI panels, borders)
**Lagoon Bloom Clear** · #A1E3D8

### Slot 3: Supporting neutral (body text areas)
**Cerulean Silk Clear** · #81CBD9

### Slot 4: Accent (CTAs, buttons, highlights)
**Azure Core Vivid** · #2099D5

### Slot 5: Deep contrast (headings, anchoring elements)
**Indigo Nocturne Soft** · #222744

## Application Guidelines

### Do
- Use **Seafoam Whisper Soft** as the dominant surface color (60% of the layout)
- Use **Lagoon Bloom Clear** for secondary panels and content areas (30%)
- Reserve **Azure Core Vivid** for interactive elements and calls to action (10%)
- Pair **Indigo Nocturne Soft** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Azure Core Vivid**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Seafoam Whisper Soft background + Indigo Nocturne Soft text + Azure Core Vivid CTA button
- **Card layout:** Lagoon Bloom Clear card background + Indigo Nocturne Soft heading + Cerulean Silk Clear border
- **Dark mode:** Invert Indigo Nocturne Soft as background, Seafoam Whisper Soft as text
