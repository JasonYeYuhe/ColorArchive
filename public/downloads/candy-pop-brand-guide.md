# Brand Usage Guide: Candy Pop

Bright, playful, and deliberately high-energy. Built for maximum visual impact on social media, e-commerce surfaces, and campaign landing pages.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Coral Radiant Vivid** · #E18A33

### Slot 2: Secondary (UI panels, borders)
**Citrine Tone Vivid** · #E4E44E

### Slot 3: Supporting neutral (body text areas)
**Mint Core Clear** · #38BC4E

### Slot 4: Accent (CTAs, buttons, highlights)
**Peony Core Vivid** · #D520B7

### Slot 5: Deep contrast (headings, anchoring elements)
**Azure Bloom Clear** · #A1CDE3

## Application Guidelines

### Do
- Use **Coral Radiant Vivid** as the dominant surface color (60% of the layout)
- Use **Citrine Tone Vivid** for secondary panels and content areas (30%)
- Reserve **Peony Core Vivid** for interactive elements and calls to action (10%)
- Pair **Azure Bloom Clear** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Peony Core Vivid**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Coral Radiant Vivid background + Azure Bloom Clear text + Peony Core Vivid CTA button
- **Card layout:** Citrine Tone Vivid card background + Azure Bloom Clear heading + Mint Core Clear border
- **Dark mode:** Invert Azure Bloom Clear as background, Coral Radiant Vivid as text
