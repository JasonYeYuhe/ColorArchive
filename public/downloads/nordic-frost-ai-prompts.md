# AI Prompt Templates: Nordic Frost

## Palette
- Azure Mist Muted: #E1E7EA
- Cerulean Whisper Soft: #EAF3F5
- Sapphire Pearl Muted: #CFD6DE
- Iris Veil Muted: #F9F9FB
- Cobalt Bloom Soft: #ADBBD7

## Mood Keywords
ice fog, pale horizon, nordic glass, silent white, cool precision

## Suggested Use Cases
SaaS UI, Tech landing pages, Minimal dashboards

---

## Prompt 1: Visual Design
Design a landing page using the "Nordic Frost" color palette. The colors are: Azure Mist Muted (#E1E7EA), Cerulean Whisper Soft (#EAF3F5), Sapphire Pearl Muted (#CFD6DE), Iris Veil Muted (#F9F9FB), Cobalt Bloom Soft (#ADBBD7). The mood should evoke ice fog, pale horizon, nordic glass, silent white, cool precision. Keep the layout clean and modern with generous white space.

## Prompt 2: Brand Identity
Create a brand identity system using these five colors: Azure Mist Muted (#E1E7EA), Cerulean Whisper Soft (#EAF3F5), Sapphire Pearl Muted (#CFD6DE), Iris Veil Muted (#F9F9FB), Cobalt Bloom Soft (#ADBBD7). The first color is the primary brand color, the second is secondary, the third is a supporting neutral, the fourth is an accent for CTAs and highlights, and the fifth provides deep contrast for text and anchoring elements. The brand mood is: ice fog, pale horizon, nordic glass, silent white, cool precision.

## Prompt 3: Social Media
Design a set of Instagram story templates using the "Nordic Frost" palette (Azure Mist Muted (#E1E7EA), Cerulean Whisper Soft (#EAF3F5), Sapphire Pearl Muted (#CFD6DE), Iris Veil Muted (#F9F9FB), Cobalt Bloom Soft (#ADBBD7)). The feel should be ice fog, pale horizon, nordic glass, silent white, cool precision. Include text overlays, product frames, and quote cards that work as a cohesive series.
