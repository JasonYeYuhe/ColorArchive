# Brand Usage Guide: Nordic Frost

A cool, restrained palette that feels precise and airy. Works for technical products, productivity tools, and any interface that needs to feel focused and uncluttered.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Azure Mist Muted** · #E1E7EA

### Slot 2: Secondary (UI panels, borders)
**Cerulean Whisper Soft** · #EAF3F5

### Slot 3: Supporting neutral (body text areas)
**Sapphire Pearl Muted** · #CFD6DE

### Slot 4: Accent (CTAs, buttons, highlights)
**Iris Veil Muted** · #F9F9FB

### Slot 5: Deep contrast (headings, anchoring elements)
**Cobalt Bloom Soft** · #ADBBD7

## Application Guidelines

### Do
- Use **Azure Mist Muted** as the dominant surface color (60% of the layout)
- Use **Cerulean Whisper Soft** for secondary panels and content areas (30%)
- Reserve **Iris Veil Muted** for interactive elements and calls to action (10%)
- Pair **Cobalt Bloom Soft** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Iris Veil Muted**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Azure Mist Muted background + Cobalt Bloom Soft text + Iris Veil Muted CTA button
- **Card layout:** Cerulean Whisper Soft card background + Cobalt Bloom Soft heading + Sapphire Pearl Muted border
- **Dark mode:** Invert Cobalt Bloom Soft as background, Azure Mist Muted as text
