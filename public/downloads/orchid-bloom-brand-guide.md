# Brand Usage Guide: Orchid Bloom

This set is intentionally expressive: floral, polished, and bright enough for social surfaces while still staying curated.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Orchid Bloom Clear** · #B7A1E3

### Slot 2: Secondary (UI panels, borders)
**Plum Radiant Clear** · #8A4AC9

### Slot 3: Supporting neutral (body text areas)
**Peony Bloom Vivid** · #EF95E0

### Slot 4: Accent (CTAs, buttons, highlights)
**Rose Core Soft** · #A45188

### Slot 5: Deep contrast (headings, anchoring elements)
**Mint Whisper Muted** · #EDF2EE

## Application Guidelines

### Do
- Use **Orchid Bloom Clear** as the dominant surface color (60% of the layout)
- Use **Plum Radiant Clear** for secondary panels and content areas (30%)
- Reserve **Rose Core Soft** for interactive elements and calls to action (10%)
- Pair **Mint Whisper Muted** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Rose Core Soft**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Orchid Bloom Clear background + Mint Whisper Muted text + Rose Core Soft CTA button
- **Card layout:** Plum Radiant Clear card background + Mint Whisper Muted heading + Peony Bloom Vivid border
- **Dark mode:** Invert Mint Whisper Muted as background, Orchid Bloom Clear as text
