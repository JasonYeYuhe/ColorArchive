# Brand Usage Guide: Nocturne Tech

A near-black base with electric violet, cobalt, and magenta accents. Good for AI tools, music products, and technical launch pages.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Indigo Ink Muted** · #1D1F2A

### Slot 2: Secondary (UI panels, borders)
**Violet Dusk Clear** · #372886

### Slot 3: Supporting neutral (body text areas)
**Cobalt Core Vivid** · #205CD5

### Slot 4: Accent (CTAs, buttons, highlights)
**Fuchsia Radiant Vivid** · #E133E1

### Slot 5: Deep contrast (headings, anchoring elements)
**Aqua Bloom Soft** · #ADD7D7

## Application Guidelines

### Do
- Use **Indigo Ink Muted** as the dominant surface color (60% of the layout)
- Use **Violet Dusk Clear** for secondary panels and content areas (30%)
- Reserve **Fuchsia Radiant Vivid** for interactive elements and calls to action (10%)
- Pair **Aqua Bloom Soft** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Fuchsia Radiant Vivid**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Indigo Ink Muted background + Aqua Bloom Soft text + Fuchsia Radiant Vivid CTA button
- **Card layout:** Violet Dusk Clear card background + Aqua Bloom Soft heading + Cobalt Core Vivid border
- **Dark mode:** Invert Aqua Bloom Soft as background, Indigo Ink Muted as text
