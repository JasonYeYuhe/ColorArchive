# Brand Usage Guide: Quiet Luxury

A restrained palette built around pale blush, sand, oat, and deep grounding neutrals. Use it when the interface should feel expensive without becoming cold.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Blush Whisper Muted** · #F2EDF0

### Slot 2: Secondary (UI panels, borders)
**Apricot Pearl Soft** · #E4DBC8

### Slot 3: Supporting neutral (body text areas)
**Honey Bloom Muted** · #C9CDB7

### Slot 4: Accent (CTAs, buttons, highlights)
**Olive Tone Muted** · #9FAB87

### Slot 5: Deep contrast (headings, anchoring elements)
**Merlot Ink Muted** · #2A1D1F

## Application Guidelines

### Do
- Use **Blush Whisper Muted** as the dominant surface color (60% of the layout)
- Use **Apricot Pearl Soft** for secondary panels and content areas (30%)
- Reserve **Olive Tone Muted** for interactive elements and calls to action (10%)
- Pair **Merlot Ink Muted** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Olive Tone Muted**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Blush Whisper Muted background + Merlot Ink Muted text + Olive Tone Muted CTA button
- **Card layout:** Apricot Pearl Soft card background + Merlot Ink Muted heading + Honey Bloom Muted border
- **Dark mode:** Invert Merlot Ink Muted as background, Blush Whisper Muted as text
