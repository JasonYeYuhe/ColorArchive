# Brand Usage Guide: Editorial Warmth

The palette leans into apricot, amber, garnet, and muted olive so the page feels human and tactile rather than sterile.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Apricot Whisper Soft** · #F5F1EA

### Slot 2: Secondary (UI panels, borders)
**Amber Silk Soft** · #C9C092

### Slot 3: Supporting neutral (body text areas)
**Citrine Tone Muted** · #ABAB87

### Slot 4: Accent (CTAs, buttons, highlights)
**Garnet Velvet Soft** · #90475F

### Slot 5: Deep contrast (headings, anchoring elements)
**Olive Dusk Muted** · #5C6647

## Application Guidelines

### Do
- Use **Apricot Whisper Soft** as the dominant surface color (60% of the layout)
- Use **Amber Silk Soft** for secondary panels and content areas (30%)
- Reserve **Garnet Velvet Soft** for interactive elements and calls to action (10%)
- Pair **Olive Dusk Muted** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Garnet Velvet Soft**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Apricot Whisper Soft background + Olive Dusk Muted text + Garnet Velvet Soft CTA button
- **Card layout:** Amber Silk Soft card background + Olive Dusk Muted heading + Citrine Tone Muted border
- **Dark mode:** Invert Olive Dusk Muted as background, Apricot Whisper Soft as text
