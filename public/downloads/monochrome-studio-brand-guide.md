# Brand Usage Guide: Monochrome Studio

A near-neutral palette spanning pale mist to deep ink with subtle warm and cool undertones. Ideal for typography-first layouts and restrained editorial work.

---

## Color Roles

### Slot 1: Primary (backgrounds, hero surfaces)
**Honey Whisper Muted** · #F2F2ED

### Slot 2: Secondary (UI panels, borders)
**Azure Mist Muted** · #E1E7EA

### Slot 3: Supporting neutral (body text areas)
**Olive Silk Muted** · #B2BC9F

### Slot 4: Accent (CTAs, buttons, highlights)
**Cobalt Dusk Muted** · #475166

### Slot 5: Deep contrast (headings, anchoring elements)
**Merlot Ink Muted** · #2A1D1F

## Application Guidelines

### Do
- Use **Honey Whisper Muted** as the dominant surface color (60% of the layout)
- Use **Azure Mist Muted** for secondary panels and content areas (30%)
- Reserve **Cobalt Dusk Muted** for interactive elements and calls to action (10%)
- Pair **Merlot Ink Muted** with light backgrounds for readable body text

### Don't
- Don't use the accent color (**Cobalt Dusk Muted**) for large background areas
- Don't combine more than 2 saturated colors in the same section
- Don't use light palette colors for body text on white backgrounds — check contrast first

## Suggested Pairings
- **Hero section:** Honey Whisper Muted background + Merlot Ink Muted text + Cobalt Dusk Muted CTA button
- **Card layout:** Azure Mist Muted card background + Merlot Ink Muted heading + Olive Silk Muted border
- **Dark mode:** Invert Merlot Ink Muted as background, Honey Whisper Muted as text
