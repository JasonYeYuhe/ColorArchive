## Description (4000 char max)

ColorArchive is the ultimate color reference for designers, developers, and creatives. Browse 5,446 algorithmically generated colors organized by 9 color families, 48 hue roots, 14 lightness bands, and 8 chroma levels.

BROWSE & DISCOVER
• Explore 5,446 colors across 9 families — Red, Orange, Yellow, Lime, Green, Teal, Blue, Purple, Pink
• Filter by family and sort by hue, lightness, or name
• Each color features a unique poetic name like "Cobalt Shadow Vivid" or "Amber Pearl Muted"

INSTANT COLOR VALUES
• Copy HEX, RGB, and HSL values with one tap
• View hue, saturation, and lightness properties at a glance
• Navigate related colors in the same family

FAVORITES
• Save any color to your favorites for quick access
• Build your personal color library

SEARCH
• Find colors by name, HEX code, or color family
• Instant results across all 5,446 colors

BUILT FOR DESIGNERS
• Every color is generated from a systematic naming convention used by professional designers
• Consistent hue/lightness/chroma grid ensures colors work together harmoniously
• Perfect companion to the full ColorArchive web platform at colorarchive.org

COMING SOON
• Palette creation and export
• macOS, iPadOS, and watchOS support
• Sync favorites across devices
• Design token export (CSS, Tailwind, Figma)

## App Review Notes

This app is a companion to the ColorArchive web platform (colorarchive.org). It generates all 5,446 colors algorithmically on-device — no network connection is required for core functionality. The app is a color reference tool for designers and developers.

There is an existing app called "Color Archive" (with a space) by Colin Wright. Our app "ColorArchive" (one word) is a different product with different functionality — it's a comprehensive color encyclopedia vs. a simple palette saver.
