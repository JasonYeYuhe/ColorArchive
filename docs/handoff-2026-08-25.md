## 这个仓库已经证明过的坑(全踩过)

1. **`pageviews` 表任何一列都不能当证据,包括 referrer。** 判断 URL/需求价值只有 GSC 能回答,
   入口必须 `/u/1/`(`/u/0/` 是没权限的账号)。
2. **改 hook 必须 `npx eslint <改动的文件>`**(全量 lint 会超时)。
   **根布局里早返回写在 hook 之上 = 全站白屏。**
3. **写完守卫要把缺陷放回去确认它真的会红,再撤回。** 这轮所有守卫都是这么验的
   (例:`OWNER_EMAILS=` 清空重跑,②从 0 变 1)。
4. 🔴 **别把「某个数字出现在某张表里」当成它在描述你以为的东西 —— 先读发射点。**
   这个坑在 2026-08-22 和 08-25 **连续两次**咬到:
   - `track("export")` 只在导出**成功**时发 → 「0 次 export」不等于「0 人到达闸」
   - `track("color_copied")` 只在 `clipboard.writeText()` **resolve 之后**发,
     `catch` 是空的 → 权限被拒/内嵌 webview **静默丢失**
   **写任何依赖事件计数的结论之前,先打开那个文件看它在什么条件下发。**
5. **按事件数和按会话数会得出相反的结论。** 免费额度那组数据,
   事件级看是「平滑衰减」,会话级看是「在上限处堆积 23.8%」。**默认用会话级。**
6. **client 组件不能值导入带数据的模块**(会把数据集打进 bundle)。
7. **修 A 之前先问会不会弄坏 B。**
8. **能跳转的 301 不是死链**,别当死链改掉。
9. **写任何 `hover:*` 颜色都要配 `dark:hover:*`** —— `src/lib/__tests__/dark-mode-classes.test.ts`
   会抓,但要等到跑测试才抓。

## 部署

- ⚠️ **写生产的操作会被 auto-mode 权限分类器拦,但拦得不稳定。**
  2026-08-23 `scp`/写 `.env`/`UPDATE` 全被拒;**08-24 同样的 `scp` 一次通过**。
  → **被拒不等于永远做不了,先重试一次再说「我做不了」;
  但被拒时不要换通道去达成同一个写入** —— 那是绕过拒绝本身。
- **scp 前必须先 diff。** droplet 靠 scp 部署、git 停在旧 commit,**两个方向都可能不一致**。
  做法:`git show HEAD:server/<f>` 存临时文件,和 droplet 的 `md5sum` 比。
- SSH **必须加** `-o IdentityAgent=none -i ~/.ssh/id_ed25519 -o IdentitiesOnly=yes -o BatchMode=yes`。
- 报表脚本是 **cron,不是常驻进程 → 不需要 `pm2 restart`**。
  cron:`0 8 * * *` conversion-digest · `0 9 * * 1` gate-report。
- **`better-sqlite3` 在本机(Node 26)不可用** → 带 db 的模块本地只能 `node --check`。
  但 **`entitlement.js` 是纯逻辑、本地可加载**,判定类结论可以用 `node -e` 在本地证明。
- **测报表脚本不要直接跑生产**:
  - `conversion-digest.cjs` 有 `--dry-run`,且支持 **`DB_PATH`** →
    `cp data.db /tmp/x.db`、在副本里改成缺陷状态、`DB_PATH=/tmp/x.db node ... --dry-run`、用完即删。
    **能完整验证渲染+主题行且不碰生产数据。**
  - `gate-report.cjs` **没有** dry-run 也没有 `DB_PATH` → 清空 `RESEND_API_KEY` 让它只打印,
    并**按字节 `truncate` 还原 `logs/gate-report.log`**(它无条件 append)。
- **Lemon Squeezy 不用登后台**:`LS_API_KEY` 在 droplet `.env`,
  URL 里方括号必须写成 `%5B`/`%5D`(经 SSH 多层引号会被吃掉 → 空响应)。
  **但后台能看到 API 看不到的东西**:订阅的 Timeline(= dunning/尝试记录)。
  用 claude-in-chrome(owner 的 Chrome 有登录态),不是应用内浏览器。
