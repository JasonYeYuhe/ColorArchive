## 会话协议 / 验证命令 / 已证明的坑

见 `docs/handoff-2026-08-26.md` 的同名章节,**那几节仍然有效**(只有时间敏感项过期了)。
本轮新增的坑:

- 🔴 **删了路由要 `rm -rf .next` 再 typecheck** —— 旧的 `.next/types/validator.ts` 还引用已删页面,
  会报一个假的 TS2307。
- 🔴 **`permanent: true` 产生的是 308 不是 301**(全站 29 条 redirect 都是 308,一致)。
- 🔴 **`/compare/` 收 hex 不收色号 id**,`sanitizeHex()` 补 `#`,
  **非法值静默回落到默认色** —— 传色号 id 会得到「正常加载但颜色是错的」页面。
- 🔴 **浏览器窗格的文档是 `visibilityState: "hidden"`** → Chrome 不投递 IntersectionObserver 回调,
  曝光类事件在那里测不出回调;**后台标签页里 `window.scrollTo` 也完全无效**,要先 `tabs_select`。
