## 注意事項

1. **特許印紙 ≠ 収入印紙** — 郵便局で「特許印紙」を指定して購入
2. 「標準文字」と記載することで、フォント・サイズを問わず「ColorArchive」の文字列を保護
3. 商標の枠は 8cm × 8cm が標準（最大 15cm × 15cm）
4. 紙出願の場合、別途「電子化手数料」¥4,000 の請求が後日届く
5. 出願から審査結果まで約 8〜12ヶ月
6. 審査通過後、登録料 ¥34,400 を30日以内に納付

## 出願後の流れ

1. **出願** → 出願番号が通知される（1-2週間）
2. **方式審査** → 書類の形式チェック（1-2ヶ月）
3. **実体審査** → 類似商標の有無等を審査（6-10ヶ月）
4. **登録査定** → 登録料 ¥34,400 を納付（30日以内）
5. **商標登録** → 商標権発生（5年間有効）
